Type a sentence. Get a puzzle level that can be won.

A tool for puzzle-game level designers. It learns a game's real rules from its code, builds the level you ask for, and wins it in the real game before handing it over.

The problem

Nobody knows if a new puzzle level can be won until someone sits down and plays it.

WhoLevel designers at small puzzle-game studios and solo developers, who ship 50 to 200 hand-made levels per game.
TodayEvery level is drawn by hand and then played by hand to check that it works. Shortcuts and dead ends that slip through reach the players.
With Level-ForgeAsk in plain words. Get a level in the game's own file format, with its solution, proof that it needs the skills you asked for, and a measured difficulty.

How it works

Part 1 happens once per game and produces a rule book. Part 2 runs for every request and uses that rule book at every step.

InputThe game's codeand the levels that ship with it
→
Part 1 · once per gameLearn the rulesAn AI coding assistant reads the code, writes down each rule with the line it came from, and tests each rule in the real game. Words the game ignores are marked.
→
OutputRule bookrules · file format · level checker · solver
▼ every step below uses the rule book ▼
1UnderstandWhich skills? How hard?
2Possible?If not, refuse and say why.
3BuildSeveral levels in the game's file format.
4PlaySearch finds the shortest solution. The real game replays it.
5Fix or labelRepair what failed. Say what was proven.
In: your sentencePart 2 · runs for every requestOut: level file, solution, proof

Where the AI is

Coding assistant (Claude)

Read the 4,000-line game engine and wrote the rule book: 30 rules, each with the line of code it came from and a test in the real game.

Search program

Tries every possible move to decide whether a level can be won, what the shortest solution is, whether a skill is really needed, and how many traps there are.

Language model (Google Gemini)

Written to read free-form requests in step 1. It is not running in this test version because no working API key is set up. A keyword reader does step 1 in every result on this page.

    Run it yourself

    On Linux or macOS

    git clone REPO_URL
cd level-forge
./build_engine.sh      # once, about 2 minutes
./run_demo.sh          # http://localhost:8765

    Without an API key the program runs in this same test version and says so at the top of the page.

    What it costs

    • Data: none to collect. It only needs the game's own code.
    • Computer: one ordinary computer, no graphics card. Most levels take under a second. Hard ones take about 15 seconds.
    • Language model: optional.
    • New game: one rule book. The second game took about an hour.
